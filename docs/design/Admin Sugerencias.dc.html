1. API web · POST /api/suggestions

Se agrega source: "quick". Con ese valor no se exigen category_id ni title; se mantienen Turnstile y el rate limit actuales. El wizard sigue funcionando igual (source ausente = "wizard").

// body (Zod)
{
  source: "quick",
  name: string(2..120),            // nombre del lugar o actividad
  where: string(2..160),           // ciudad o dirección
  link?: url,                      // web, Instagram o Google Maps
  why?: string(..500),             // comentario libre
  locale: "es" | "he" | "en" | "ru",
  turnstileToken: string
}
// guarda en suggestions:
//   suggestion_type = "new_place_with_experience"
//   name_i18n = { [locale]: name }, location = { city: where }
//   metadata.source = "quick", metadata.why = why, metadata.link = link
//   metadata.google_place_id = parseado de link si es de Google Maps

2. Detección de duplicados

Se reutiliza duplicate-detection.ts. Orden: (1) google_place_id si se pudo sacar del link (maps.app.goo.gl se resuelve siguiendo el redirect en el servidor); (2) nombre normalizado + ciudad; (3) nombre parecido (trigram ≥ 0,6) en la misma ciudad. Si hay coincidencia, se marca flagged_possible_duplicate y possible_duplicate_of como hoy. Nunca bloquea el envío.

3. Admin · SuggestionsSlideover.vue

Si metadata.source === "quick": badge «Sugerencia rápida», UAlert info con la lista de campos que faltan (categoría, edades, horario u «horario desconocido», título) y botones «Completar desde Google» (usa el autocompletado de lugar que ya tiene el formulario de edición) y «Editar». «Aprobar y crear» queda deshabilitado con tooltip hasta completar. Se muestra «Lo que escribió el usuario» (dónde, link, por qué). El aviso de duplicado y «Fusionar» no cambian.

Lista (suggestions.vue): filtro nuevo «Origen: Rápida / Wizard» y badge en la columna. Agregar las claves de i18n en los 4 idiomas.

4. Confirmación al usuario

La web responde 201 y muestra «¡Gracias! La revisamos y, si encaja, la sumamos en unos días». Si se detectó un duplicado no se le dice nada distinto al usuario.
