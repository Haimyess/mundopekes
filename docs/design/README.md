# Diseño MVP (Claude Design)

Export del proyecto de Claude Design «MundoPekes Mobile Design», incorporado el 2026-11-09.
Es material de referencia: no se compila ni se sirve desde ninguna app.

| Archivo | Uso |
|---|---|
| `Entrega Desarrollo.dc.html` | Documento de entrega: tokens, tipografía, breakpoints, reglas por pantalla, estados, RTL y accesibilidad |
| `MundoPekes App Kit.dc.html` | Componentes con specs (g0–g9), base de los wrappers sobre Nuxt UI |
| `Web & Screens.dc.html` | Prototipo web móvil y pantallas por flujo, fuente de verdad de pantallas y comportamiento |
| `Web Escritorio.dc.html` | Layout de 1200 px en adelante |
| `Web Hebreo.dc.html` | Pantallas en hebreo y reglas RTL |
| `Flujo Busqueda Mapa.dc.html` | Mapa de pantallas y transiciones |
| `Admin Sugerencias.dc.html` | Soporte de la sugerencia rápida en el admin |
| `App.dc.html` | Variante React Native, después del lanzamiento |
| `MVP Pendientes.dc.html` | Exploración; lo vigente está en los archivos anteriores |

Para verlos, abre los `.dc.html` en un navegador desde esta carpeta (usan `support.js`,
`image-slot.js`, `ios-frame.jsx` y `assets/`).
